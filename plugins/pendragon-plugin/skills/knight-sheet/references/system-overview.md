# Pendragon: edition and sheet map

This plugin targets **Pendragon 6th edition**, the Arthurian game of knights,
loyalties, reputation and family legacies. Adventures and courtly choices interact
with a longer campaign rhythm, including the Winter Phase. The Gamemaster
adjudicates the world and consequences. A sheet is a record and dice companion,
not a campaign simulator.

The [official rules wiki](https://pendragonwiki.chaosium.com/rules/) describes the
6e Starter Set rules. Full character creation belongs to the 6e Core Rulebook.
Do not treat the 2022 preview quickstart, earlier 5.x tables, or the uncataloged
alternate Pendragon plugin as the contract for this package.

| Sheet area | Use |
| --- | --- |
| Characteristics | SIZ, DEX, STR, CON, APP and calculated combat values |
| Traits | Paired personality tendencies; distinguish base pair values from bonuses |
| Passions | Strong loyalties, loves and commitments with narrative consequences |
| Skills and combat | Knightly/social abilities, armor, weapons and damage |
| Mounts and equipment | Horse statistics and possessions |
| Chronicle | Family, Glory, aspirations and Winter Phase notes |

The runtime provides d20 checks, opposed resolution, bounded d6 damage formulas
and derived statistics. It does not perform culture/religion allocation, family
history generation, Glory awards, automatic experience advancement or a complete
Winter Phase. Those remain table choices and manual entries. The current UI is
dark-only. Use [creation](character-creation.md), [core rules](core-rules.md) and
[tool contracts](tool-contracts.md) for the relevant next step.
